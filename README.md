# IDeal: A Part-of-Speech Tagging Corpus for Bahasa Indonesia with Linguist-Based Label Validation


## Introduction

This repository is a derivative and extended version of the Indonesian POS tagging corpus introduced in the paper:

> Fu, S., Lin, N., Zhu, G., & Jiang, S. (2018). *Towards Indonesian Part-of-Speech Tagging: Corpus and Models*. Proceedings of LREC 2018.

The original work introduced an Indonesian part-of-speech (POS) corpus containing more than 355,000 tokens and a POS tagset consisting of 29 tags.

This repository provides additional processing and improvements on top of the original corpus, including corpus correction, restructuring, normalization, annotation refinement, and dataset preparation for further NLP research and benchmarking purposes.

The repository was created by forking the publicly accessible GitHub repository associated with the original work. The original repository did not explicitly specify an open-source license at the time this derivative repository was created.

All original credits remain with the original authors. This repository only claims ownership of the newly added modifications, corrections, annotations, and restructuring contributed in this derivative work.
